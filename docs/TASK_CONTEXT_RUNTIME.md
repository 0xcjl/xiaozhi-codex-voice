# 后台任务与重连运行说明

仅在独立账号、回环原生设备入口启用。官方小智配置、固件、日常 Codex 登录不变。不开启本功能时保留已有语音路由行为。

## 配置

在项目私有运行配置的 `codex_realtime` 中增加：

```json
{
  "device_runtime": {
    "enabled": true,
    "state_dir": "/absolute/project/private/device-runtime-state",
    "task_timeout_seconds": 180
  }
}
```

状态目录必须位于任务工作区及登录目录之外，由服务用户独占；目录权限 0700，SQLite 文件 0600。单一服务进程持有文件锁。只接受可撤销的 native2 设备凭据，不接受匿名 OTA 凭据。后台模型固定 `gpt-6.1-terra`，返回模型不符即拒绝，不自动降级。

## 会话与任务

恢复范围是“控制台用户 + 订阅连接 + 设备 MAC”。首次创建一个持久语音线程，之后使用同一 ID 的 `thread/resume`；间隔发问、断开 WebSocket 或重启服务不新建线程。恢复失败会报错，不偷偷创建另一个线程。不同范围互相隔离。近期恢复缓存最多 32 条、共 24000 字符，每条最多 2000 字符；任务记录以 developer 数据项注入，不伪装成用户发言。专用 CODEX_HOME 的 Codex 持久线程另有其自身历史，缓存上限不代表删除了那份历史。

原生语音的 backing Codex 注册四项动态工具：启动任务、查询状态、重播报告、明确取消任务。查询不派发工作，同一工具 callId 只创建一次。任务 UUID 是主标识，语音代号是固定可读别名；自然语言中先提及的工作不保证先抵达服务端，结果必须按各任务自身提示和 UUID 对应。

任务在注册工作区的独立 `jobs/<UUID>` 子目录执行，最多 2 个并行、每范围最多 8 个活动任务、全进程最多 32 个活动任务。每范围最多保存 128 个任务，达到上限拒绝新增，不静默清空历史；本版本不提供自动归档。每个后台任务使用临时 Codex 线程，避免产生大量持久聊天列表项。工作区写入沙箱关闭网络；额外通过提示禁止读取其他项目、凭据和系统文件。这不等于操作系统完全隔离所有读取权限。

设备断线不取消后台任务。服务重启或停止会把未完成任务记为中断，不自动重跑；已完成结果和待播报事件保留。访问撤销时活动工作在定期复核后停止。超时或明确取消先中断所属 Codex turn，再清理本服务创建的工作进程组，不杀其他 Codex 进程。

## 原生播报

报告通过原生 `appendSpeech` 生成，只有一个上下文写入者处理关联回执。服务端暂存最多 40 秒 PCM，核对任务代号、其他任务代号和数字事实后，按 16kHz 单声道 Opus 发给设备。此缓存位于 Mac 服务进程，ESP32 不保存任务队列或完整音频。适配层不落盘原始录音；Codex 专用线程保存文本历史。

音频生成和实际播放使用分离的超时。插话由设备显式 abort 或真实用户 turn 触发，不以轻微环境音音量推断。插话后先等待本轮回答，最长 35 秒，随后恢复报告；每条报告最多自动尝试两次，失败保留未确认状态，可明确要求重播。普通答复仍优先原生语音，不使用 Mac 本地 TTS 作为设备的输出替代。

代号和数字核验不能证明任意长文本的完整语义正确。`audio_sent` 表示有效 PCM 已发送完毕，不是物理扬声器已被真人听到的证明。真实设备播放须另有实机听感证据，不能由受控合成音频测试替代。

## 回退

停止项目设备入口后，把项目私有运行配置恢复为启用前备份，即可退回旧语音模式。保留新 SQLite 数据，不 DROP 或清库；重新启用仍使用原状态目录。此操作不会恢复或改变实体设备的 OTA；实机回退另按 [设备回退说明](DEVICE_ACCESS_RUNBOOK.md) 执行。

本机隔离验收包括：状态机与权限、真实 CLI 并发写文件独立读回、合成音频派发、离线完成、进程重启后的原生报告与记忆恢复，以及报告插话恢复。首轮后端合并按用户要求未重复真人测试；后续实体接入和工具联调以各阶段输出记录为准。

后续已定位并修复 SCTP 初始化冲突、数据通道编号奇偶与 DTLS 角色不符、ICE 检查关闭后残留问题，增加阶段期限和最多三次恢复；详见 [控制通道稳定性说明](CONTROL_CHANNEL_STABILITY.md)。连续 20 次最终均成功，首次 16 次成功，底层 ICE/DTLS 停滞仍通过重试恢复，不能宣称全天稳定或因此切换实体设备。超时日志只记录握手阶段与状态，不记录 SDP、凭据或对话内容。

设备 MCP 工具、实际模型记录和本连接临时授权详见 [设备 MCP 运行说明](DEVICE_MCP_RUNTIME.md)。
