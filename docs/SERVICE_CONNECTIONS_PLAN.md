# 服务连接配置与稳定性验收

目标：控制台统一保存服务连接，API 复用现有模型配置，订阅语音选择服务端注册的运行节点；设备配置只能由其所有者修改。保存不代表连通。官方控制台与固件不变。

1. 新增独立连接配置与设备关联表的迁移文件（本轮不执行实际数据库迁移），管理接口限制超级管理员且检查所有权，修订号防止覆盖并发编辑。
2. 新增控制台配置页：API 模型引用、订阅语音连接、启停、设备选择与恢复默认。不会复制 API 密钥或把订阅凭据传给浏览器。
3. 服务端按受信配置解析选择：API 沿用普通语音链路，订阅进入既有 Codex realtime 链路；关闭或失效的选择报错，避免默默换账号或模型。
4. 新增无数据库的 Java 单元测试、前端单元/构建检查、Python WebSocket/RTC 回归与合成语音长连接验收。

单独的订阅网页登录、Google 控制台登录、跨节点代理和运行进程重启后的会话恢复仍需后续实现；界面必须准确展示这些能力的状态。
