# 后台任务与跨重连恢复合并

边界：仅项目隔离服务、测试数据、独立 Codex 登录。无真人复测、固件操作、官方配置变更、日常登录变更或提交。

1. 复用既有 AckBroker、原生 appendSpeech 和原型的播报关联规则；单一上下文写入者，有歧义时不猜回执。
2. 每个账号连接与设备保存固定的持久线程 ID。断线后 thread/resume，并用有界文字初始项恢复原生语音；恢复失败不悄悄新建线程。后台短任务使用独立临时线程。
3. 在服务端私有 SQLite 保存有界恢复缓存、任务身份、状态与待播报事件。与工作目录和日常登录隔离；不保存原始录音或订阅 token。
4. 原生语音的 backing Codex 通过受控动态工具启动、查询和重播后台任务。任务在独立子目录、固定注册工作区内运行，禁止网络/安装/外部消息/凭据与系统改动。最多两个任务并行，超时终止所属进程组；断语音不取消任务，撤销认证会取消。
5. 完成报告先暂存服务端 PCM，核对当前报告身份与数字，再流式交给设备；插话后限次重试，断线未完成交付留待重连。任务结果以持久记录为准，不以模型猜测为准。
6. 验收：单元状态机/并发/超时/重复工具调用/越权；真实 CLI 文件任务并发与独立读回；真实控制台授权和 WebSocket；合成音频触发任务及恢复语音；日常凭据哈希和回环监听检查。

服务进程重启将排队或运行任务标为中断，不自动重跑；结果与未完成播报保留。语音缓存有界不等于 Codex 持久线程全部历史被删除；线程保存在本连接专用 CODEX_HOME，不进入日常账号目录。
